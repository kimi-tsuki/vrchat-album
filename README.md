# VRChat 本地相册

把电脑里的 VRChat 照片整理成一个自动更新的网页相册。拍完照回来，就能按世界、日期和游玩场次回看，给喜欢的照片加星标、标签和备注。

原照片留在原来的位置，相册不会移动、删除或覆盖它们。照片和整理记录保存在你的电脑上，运行相册不需要注册账号，也不需要上传照片。

当前版本：**0.2.1** · [更新日志](CHANGELOG.md) · [反馈问题](https://github.com/kimi-tsuki/vrchat-album/issues) · [参与贡献](CONTRIBUTING.md)

## 能做什么

- 自动检查照片文件夹及其子文件夹，默认每 20 秒更新一次。
- 从照片自带的 XMP 信息读取世界名称和世界 ID，按世界、日期或游玩场次浏览。
- 按世界和月份筛选，搜索世界名、世界 ID、日期、文件名、标签和备注。
- 给照片加星标，编辑世界名、标签和备注，也可以批量整理同一场的照片。
- 打开完整原图，用左右方向键翻图，用 Esc 关闭查看器。
- 把字节完全相同的照片合并显示，所有原文件继续保留。
- 导出整理记录 JSON，或备份本地数据目录。

## 第一次使用：Windows

**下载并解压 → 双击“打开相册.cmd” → 在网页选择照片目录。** 已安装 Python 3.10 或更新版本时，启动器会自动准备相册环境，不必先打开终端输入安装命令。

### 1. 下载并解压

**不需要安装 Git。** 打开 [项目页面](https://github.com/kimi-tsuki/vrchat-album)，点击绿色 **Code → Download ZIP**，解压到准备长期使用的文件夹。

进入解压后的 `vrchat-album-main` 文件夹，确认能看到 `app.py`、`bootstrap.py`、`install.py` 和 `打开相册.cmd`。不要直接在压缩包中运行，也不要把程序放进要扫描的照片文件夹中。

### 2. 双击“打开相册.cmd”

启动窗口会自动检查项目的 `.venv`、Python 版本和 Pillow。首次使用时，它会在项目内创建独立的 `.venv`，下载并安装依赖；已经准备好的环境会直接复用，然后打开浏览器。

- **电脑还没有 Python？** 窗口会提示你从 [Python 官网](https://www.python.org/downloads/)安装 **Python 3.10+**（建议 3.12+），安装后再次双击。启动器不会自动下载或安装 Python。安装方式见 [Python 官方说明](https://docs.python.org/3/using/windows.html)。
- 安装依赖需要联网访问 Python 包索引；完成后，日常整理和浏览在本机进行，不需要联网。
- 安装或启动失败时，窗口会保留错误信息供检查；修复后再双击即可。依赖只安装到项目 `.venv`，不会安装到系统 Python。
- 相册运行期间保持这个窗口打开。关闭浏览器不会停止相册；在窗口按 **Ctrl+C** 可以停止。

### 3. 在网页选择照片目录

首次打开会显示欢迎卡。确认建议的 **Pictures / VRChat** 目录，或点选择文件夹按钮，在系统原生窗口中找到实际照片目录；选好后点击 **开始整理**。选择器取消时保留原来的路径。如果选择器不可用，也可以手动填写照片目录的绝对路径。

网页会立即显示寻找照片、读取图片和生成缩略图的进度。照片多时可以保持页面打开等待；原图全程只读，不会移动、删除或覆盖。支持 PNG、JPG、JPEG 和 WebP，自动包含子文件夹。

照片目录保存在相册数据目录的 SQLite 数据库中，下次双击会继续使用。以后可以在页面侧栏或顶部更换目录，不必修改启动文件。切换目录后，只展示当前来源的文件；收藏、标签、备注和自定义世界名按照片内容保留，切回原目录仍可使用。

如果另一个窗口更换了目录，未保存的单张或批量标注会保留为草稿。可以先复制或导出草稿，再明确放弃并打开当前相册；导出的草稿可手动重填，暂不支持自动导入。

默认网页地址为 **<http://127.0.0.1:18764>**。浏览器没有自动打开时，使用启动窗口显示的地址；网页中的“使用指南”也可以随时查看。

### 使用终端安装（可选）

如果已经安装 Git，也可以克隆项目。终端用户仍可单独运行安装脚本：

```text
git clone https://github.com/kimi-tsuki/vrchat-album.git
cd vrchat-album
py -3 install.py
```

只有 `python` 命令可用时，改用 `python install.py`。`install.py` 只准备环境和依赖，不扫描照片；完成后双击“打开相册.cmd”，或运行 `python bootstrap.py`。无需激活虚拟环境或修改 PowerShell 执行策略。

## 日常使用

打开相册后，左侧可以切换世界或月份。默认按世界浏览；有名称的世界优先显示，只有世界 ID 的照片显示为“未命名世界”，没有世界信息的照片显示为“未记录世界”。旧照片或经过处理的照片可能没有世界信息，可以手动补充。

点击照片进入查看器，填写世界名、标签和备注后保存。标签用逗号分隔。需要整理多张照片时，点“选择”，选中照片，再填写共同的信息；批量编辑中留空的项目会保留原有内容。查看器也支持给整场的照片填写世界名称。

新照片通常会在下一次自动扫描后出现，也可以点“重新扫描”。照片还在写入时可能暂时无法读取，等保存完成后再扫描即可。

页面顶部和底部提供 **Star on GitHub** 按钮，底部还显示可点击的 [GitHub 项目地址](https://github.com/kimi-tsuki/vrchat-album)，点击会在新标签页打开仓库。喜欢这个项目，可以登录 GitHub 后点击仓库右上角的 **Star** 支持；GitHub Star 与相册里的照片星标分别保存。页面不加载外部按钮脚本，也不请求 GitHub 统计，访问仓库时才需要联网。

需要停止时，在相册页面点“停止后台”、在运行窗口按 **Ctrl+C**，或关闭运行窗口。再次双击启动文件就能继续使用；电脑重启后也需要重新打开相册。

## 指定自己的照片文件夹

日常使用直接在网页更换目录即可，系统选择器与手动绝对路径均可使用；取消选择不会改变当前来源。

高级用户可以在相册文件夹打开终端，先停止此前运行的相册，再通过参数指定：

```text
.\打开相册.cmd --source "D:\VRChatPhotos"
```

把示例路径换成自己的照片文件夹。路径包含空格时也要保留双引号。**`--source` 优先于此前保存的目录，并保存为下次使用的目录。** 后续直接双击即可继续，无需每次输入参数。

也可以直接使用项目的 Python 环境启动：

```text
.\.venv\Scripts\python.exe app.py --source "D:\VRChatPhotos" --open-browser
```

支持 PNG、JPG、JPEG 和 WebP 图片。照片可以放在子文件夹中，无需重新排列目录。

其他启动选项：

| 参数 | 用途 | 默认值 |
| --- | --- | --- |
| `--source` | 指定并记住照片文件夹，覆盖已保存选择 | 已保存的目录；首次在网页确认 `Pictures/VRChat` 或其他目录 |
| `--data` | 索引、缩略图和整理记录的保存位置 | 相册程序旁的 `data/` |
| `--port` | 本机网页端口 | `18764` |
| `--interval` | 自动扫描间隔，单位为秒，最少 5 秒 | `20` |
| `--open-browser` | 服务可用后打开浏览器，扫描进度在页面显示 | 双击启动时自动添加 |

例如，使用自己的照片目录和数据目录：

```text
.\.venv\Scripts\python.exe app.py --source "D:\VRChatPhotos" --data "D:\VRChatAlbumData" --open-browser
```

**数据目录必须放在照片目录之外**，也不能与照片目录相同。同一个数据目录可以记住照片来源，并隔离不同来源的文件路径；按内容识别的收藏、标签和备注继续保留。只有需要完全独立的相册与整理记录时，才需要指定不同的 `--data`。

### macOS / Linux

在下载并解压的相册文件夹中，使用 Python 3.10 或更新版本安装：

```sh
python3 install.py
```

然后指定照片目录启动：

```sh
.venv/bin/python app.py --source "/path/to/VRChatPhotos" --open-browser
```

将示例路径换成自己的目录。Windows 的 `.cmd` 启动文件仅用于 Windows；其他系统使用上面的命令。

## 备份、恢复和更新

### 备份整理记录

**先停止相册，再复制整个 `data/` 文件夹**到备份位置。如果启动时使用了 `--data`，备份那个指定的数据目录。

数据目录包含索引数据库、缩略图以及你填写的世界名、标签、备注和星标。原照片不在这里，请另外备份照片文件夹。保留整理记录无法代替原图备份。

网页中的“导出整理记录”会下载 JSON，适合留档和查看。**当前没有从 JSON 导入恢复的功能**；完整恢复请使用数据目录备份。导出的 JSON 包含本地路径、文件名、世界信息和备注，请自行保管，不要附到公开问题反馈中。

### 恢复或迁移

停止相册，把备份的 `data/` 放回程序旁，或用 `--data` 指向备份数据目录，再指定原照片目录启动。如果换了电脑，还需要把原照片另行复制过去。

迁移程序文件夹时，在新位置先将旧 `.venv` 改名备份，再双击“打开相册.cmd”创建新的运行环境；也可单独运行 `install.py`。虚拟环境不能作为可直接搬运的运行环境。保留好数据目录和原照片即可。

### 更新到新版本

1. 停止相册，备份数据目录和原照片。
2. 阅读 [更新日志](CHANGELOG.md)，留意数据兼容性说明。
3. ZIP 用户下载新版本并解压到新文件夹，把原来的 `data/` 复制到新程序旁；使用自定义数据目录的用户继续指定原来的 `--data`。
4. 双击新程序的“打开相册.cmd”，自动准备环境并启动；使用自定义数据目录的用户仍通过 `--data` 指向原来的数据目录。

**从 0.1.1 升级到 0.2.0：** 旧版没有保存照片目录，因此第一次启动需要在欢迎页确认原照片目录；也可以沿用原来的 `--source` 参数直接启动。未知来源的旧文件索引会保留，确认目录后重新读取照片，收藏、标签和备注按内容沿用。首次扫描可能比日常扫描慢，无需删除原数据库；该选择之后会记住。

使用 Git 且没有本地源码改动时，也可以在停止相册后运行 `git pull --ff-only`，再运行 `python install.py`。更新时保留 `data/`；它不会随源码提交到 GitHub。

## 常见问题

### `python` 无法运行，或打开了 Microsoft Store

双击启动器会依次查找可运行的 Python。找不到时，先按 [Python 的 Windows 安装说明](https://docs.python.org/3/using/windows.html)安装 Python 3.10+，然后重新双击；不要仅下载 Python 源码包。也可以在终端检查 `py -3 --version` 或 `python --version`。

### 提示 `No module named PIL`

Pillow 没有安装到正在使用的 Python 环境。双击“打开相册.cmd”会自动检查并补齐项目依赖；仍失败时，可单独运行 `python install.py` 查看完整安装过程。不要在其他 Python 环境中安装后直接运行 `app.py`。

### 依赖安装失败

首次安装需要访问 Python 包仓库。检查网络并重试，保留终端显示的错误信息。如果正在使用公司或学校管理的电脑，请按其网络与软件安装规则处理。

### 找不到照片目录，或相册没有照片

确认 VRChat 已经在电脑上保存过照片。默认路径可能与 OneDrive、重定向文件夹或自己设置的位置不同，请在网页选择实际照片目录，或手动粘贴绝对路径。首次欢迎卡需要点“开始整理”才会确认来源。照片目录只需要可读；相册数据目录需要可写。

### 选择文件夹窗口没有出现

先检查系统选择窗口是否被浏览器挡住。若系统不支持原生选择器或返回错误，可以直接在网页填写完整路径后确认；取消选择不会切换目录。命令行 `--source` 仍可作为备用入口。

### 网页打不开，或显示无法连接后台

检查启动窗口是否仍然打开，使用它显示的地址。默认地址是 `http://127.0.0.1:18764`，请不要替换为 `localhost` 或电脑的局域网地址。关闭窗口后需要重新启动；刷新浏览器本身不会启动相册。

### 提示端口被占用

可能已经有一个相册或其他程序在使用该端口。先查看是否已有运行窗口；也可以指定其他端口：

```text
.\.venv\Scripts\python.exe app.py --port 18765 --open-browser
```

然后使用启动窗口显示的新地址。自定义照片目录时，同时保留 `--source` 参数。

### 为什么世界名、日期或场次不准确？

世界名称取自照片内的 XMP 信息；缺少名称时可以手动填写。日期优先取 `VRChat_YYYY-MM-DD_HH-mm-ss` 文件名，其次取图片日期，最后取文件修改时间。改名、重新导出或复制照片后，回退日期可能与实际拍摄时间不同。

“游玩场次”按拍照间隔估算：相邻照片相隔超过 90 分钟开始新场次。连续拍到午夜后的照片仍属于同一场，因此它不一定等同于实际登录次数。

### 为什么有些重复画面仍然显示两张？

去重比较的是完整文件的 SHA256。只有文件字节完全相同才合并显示；相同画面重新压缩、修改元数据或另存后，文件不同，仍会分别保留。合并显示不会删除任何原照片。

### 安全软件提示告警怎么办？

保留告警名称、相册版本和出现的步骤，在 [Issues](https://github.com/kimi-tsuki/vrchat-album/issues)反馈。不要为了运行相册关闭安全防护、修改执行策略或恢复被隔离的文件。

## 隐私和故障反馈

相册服务只监听 **127.0.0.1**，供当前电脑的浏览器访问。它不提供局域网共享或公网部署，也不会将照片上传到 GitHub。原图、缩略图、索引、标注、日志和本地环境都排除在 Git 提交之外。数据目录与导出 JSON 未加密，接口没有本机账号认证；本机其他进程也可访问相册。

反馈问题时，提供相册版本、操作系统、Python 版本、复现步骤和经过检查的错误文本即可。请勿上传真实照片、整个 `data/`、导出 JSON、完整日志、私人路径或凭据。截图请使用测试图片，并遮住用户名、文件夹路径及个人备注。需要最小复现时，可以用自己生成的纯色图片。

## 参与开源

欢迎反馈问题、改进安装与浏览体验、补充测试和提交代码。开发与提交说明见 [CONTRIBUTING.md](CONTRIBUTING.md)，仓库协作规则见 [AGENTS.md](AGENTS.md)。

版本号保存在 `VERSION`。修复、小优化和文档调整递增 patch；较大功能或模块重构递增 minor，并将 patch 归零。major 仅在维护者明确决定时升级。同一轮修改合并为一个版本，同步更新 `VERSION`、`CHANGELOG.md` 和 README。首个正式版本为 `0.1.0`。
