# VRChat 本地相册

把默认 VRChat 照片目录变成一个自动更新的网页相册。

## 使用

Windows 上双击 **打开相册.cmd**。它直接运行 Python，保留可见的窗口，首次整理完成后打开浏览器。相册运行期间保持此窗口打开。重复打开会复用已经运行的相册。

启动器不使用 PowerShell、不改变执行策略、不隐藏进程，也不下载或安装程序。依赖需要事先安装。

- 默认读取当前用户的 `Pictures/VRChat` 目录，包括年月目录和嵌套目录。
- 每 20 秒扫描一次；刚拍的照片在写入完成后自动出现，也可以点“立即扫描”。
- 自动从 VRChat 的 XMP 信息提取世界名，按世界、日期或游玩场次浏览。
- 日期优先取 `VRChat_YYYY-MM-DD_HH-mm-ss` 文件名；缺失时取图片日期或文件修改时间。
- 相邻拍照时间相隔超过 90 分钟视为新的游玩场次。连续拍到午夜后的照片仍算同一场。
- 内容完全相同的照片只显示一次，不移动、不删除原照片。
- 搜索世界名、日期、标签和备注，收藏照片，批量补充世界名和标签。
- 查看器支持左右方向键翻图和 Esc 关闭，原图链接可以直接查看完整照片。

关闭浏览器后，只要启动窗口还在，相册仍会自动检查新照片。关闭启动窗口、按 Ctrl+C，或在网页中点“停止后台”即可停止。电脑重启后需要再次打开相册。

照片始终留在本机。服务只监听 `127.0.0.1`，GitHub 只保存源码。索引、缩略图、世界名、收藏和备注保存在 `data/`，已通过 `.gitignore` 排除。备份相册标注时可复制整个 `data/` 目录，或在网页中导出 JSON。JSON 包含本地目录及相册信息，请按自己的需要保存。

## 依赖与手动启动

需要 Python 3.10+ 和 Pillow。Windows 启动器优先使用项目 `.venv`，其次使用现有 Codex Python，最后使用系统 Python。

其他电脑首次使用：

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

手动指定不同目录或端口：

```powershell
python app.py --source "D:\Pictures\VRChat" --port 18764
```

然后打开 `http://127.0.0.1:18764`。

默认配置适用于 Windows；在 macOS/Linux 上可用 `python app.py --source /your/photos` 手动启动。

## 检查

```powershell
python -m unittest discover -s tests -v
```

测试用生成的图片验证去重、时间解析、世界元数据、跨午夜场次、收藏持久化、增量扫描和原图不被更改，不会修改真实相册。

## 以后部署到公网

当前版本的原图、索引和标注均保留在本机。要让公网网站访问，需要增加受保护的照片同步、云端存储、身份验证和访问权限；GitHub Pages 本身无法自动读取电脑上的照片目录。不要把本地服务直接转发到公网。
