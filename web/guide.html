把漫游的照片，收进自己的相册

照片、缩略图与整理记录保留在你的电脑上。启动窗口打开时，相册默认每 20 秒检查新照片。

第一次使用

  1. 从项目仓库下载源码 ZIP 并完整解压，安装 Python 3.10 或以上版本。
  2. 在解压后的项目文件夹打开终端，运行 python install.py。Windows 也可使用 py -3 install.py；macOS / Linux 使用 python3 install.py。
  3. 看到“Pillow OK”和“安装完成”后，Windows 双击 打开相册.cmd。首次扫描完成会自动打开浏览器。
  4. 确认相册左侧显示的照片文件夹。默认是当前用户的 Pictures\VRChat，年月子目录也会扫描。

首次安装需要联网下载依赖，之后浏览相册不需要云端服务。运行期间保留启动窗口。

照片放在其他地方？

先停止已经运行的相册，在项目文件夹的终端中指定自己的照片目录。下面的路径需要换成你的实际路径；该设置只对这次启动生效。

Windows：

.\打开相册.cmd --source "D:\VRChatPhotos"

macOS / Linux：

.venv/bin/python app.py --source "/你的/VRChat照片目录" --open-browser

如果 Windows 的图片目录被 OneDrive 重定向，也需要指定实际的 VRChat 照片目录。

先这样逛逛相册

  • 左侧按世界或月份缩小范围；上方切换按世界、日期或游玩场次分组。
  • 搜索世界名、日期、文件名、标签或备注。搜索和当前筛选会一起生效。
  • 点击照片查看原图，用左右方向键翻页、Esc 关闭。世界名、标签和备注填写后需点击“保存这段回忆”。
  • 点击星标收藏照片，或用“选择”一次整理多张照片。
  • 只有照片包含相应元数据时才会自动识别世界；“未命名世界”和“未记录世界”可手动补充。

关闭、备份与更新

关闭网页后，启动窗口仍会继续扫描。按 Ctrl+C、关闭启动窗口或点网页里的“停止后台”来停止相册。

备份前先停止相册，然后复制整个项目 data/ 文件夹；若使用了 --data，备份实际指定的数据目录。它包含索引、缩略图、收藏与标注，原照片需要另行备份。网页导出的 JSON 可留档，但当前没有 JSON 导入还原功能。

更新源码前先停止相册并备份数据目录。将新版本解压到新文件夹，把原 data/ 复制过去，再运行安装命令并重新启动；使用自定义目录时，继续指定原来的 --source 和 --data。克隆仓库的用户可按 README 使用 git pull --ff-only。

找不到照片或打不开？

  • 缺少 Pillow：在项目目录重新运行安装命令，检查是否出现“安装完成”。
  • 空相册：核对左侧目录、清空搜索与筛选，并确认照片已写入完成。支持 PNG、JPG、JPEG 和 WebP。
  • 连接中断：检查启动窗口是否还在运行，重新启动后再打开 http://127.0.0.1:18764。
  • 端口被占用：关闭之前的相册，或运行 .\打开相册.cmd --port 18765 并使用新端口。
  • 安全软件拦截：先记录具体提示与文件名，在仓库提出问题以便检查。
