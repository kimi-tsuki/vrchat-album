把漫游的照片，收进自己的相册

照片、缩略图与整理记录保留在你的电脑上。选好照片文件夹后，启动窗口打开时，相册默认每 20 秒检查新照片。

Windows：第一次打开相册

  1. 打开 项目仓库，点 Code → Download ZIP，下载后完整解压。无需安装 Git。
  2. 在解压后的文件夹双击 打开相册.cmd。它会检查 Python、准备本地运行环境和依赖，然后打开网页。
  3. 如果提示未找到 Python，先从 Python 官方网站安装 Python 3.10 或以上版本（建议 3.12 或以上），再双击启动文件。启动窗口会显示下一步操作。
  4. 首次打开网页，确认建议的照片文件夹，或点“选择其他文件夹”，选好后点“开始整理”。

首次安装需要联网下载依赖，之后浏览相册不需要云端服务。请先解压，不能在 ZIP 里面直接启动；运行期间保留启动窗口。以后仍双击同一个 打开相册.cmd，已安装的环境会直接复用。

照片放在其他地方？

默认建议当前用户的 Pictures\VRChat。照片存放在其他磁盘、OneDrive 或自定义文件夹时，请选择实际的 VRChat 照片文件夹；其中的年月子目录也会扫描。

  1. 首次使用，点“选择其他文件夹”；已经打开相册时，点左侧底部“更换照片文件夹”，窄屏中在标题下方点“更换目录”。
  2. 在这台电脑的文件夹选择窗口中选中照片目录。窗口可能在浏览器后面。点取消会保留当前目录。
  3. 检查网页显示的待用路径，点击“开始整理”或“确认并开始整理”，才会真正应用这个目录。

选择窗口打不开时，展开“手动填写文件夹路径”，从资源管理器地址栏复制完整路径，例如 D:\VRChatPhotos。浏览器中的选择按钮会打开相册后台的本机选择窗口，不会上传文件。

确认后的目录会保存在本机，下次启动会继续使用。更换目录会清除当前搜索、筛选和选图状态；未保存的标注请先保存。标注和星标跟随同一张照片保留，切回原目录仍能继续回看。

第一次整理会发生什么？

相册先查找所选文件夹和子目录里的照片，再读取照片信息、合并完全相同的副本并准备缩略图。网页会显示当前阶段和处理数量；文件较多时需要一点时间，可以保持网页打开等待。

整理完成后，如果这个目录没有支持的照片，网页会明确显示空相册，可以直接选择另一个目录。支持 PNG、JPG、JPEG 和 WebP。原照片始终留在原位，合并只影响相册显示。

先这样逛逛相册

  • 左侧按世界或月份缩小范围；上方切换按世界、日期或游玩场次分组。
  • 搜索世界名、日期、文件名、标签或备注。搜索和当前筛选会一起生效。
  • 点击照片查看原图，用左右方向键翻页、Esc 关闭。世界名、标签和备注填写后需点击“保存这段回忆”。
  • 点击星标收藏照片，或用“选择”一次整理多张照片。
  • 只有照片包含相应元数据时才会自动识别世界；“未命名世界”和“未记录世界”可手动补充。

关闭、备份与更新

关闭网页后，启动窗口仍会继续扫描。按 Ctrl+C、关闭启动窗口或点网页里的“停止后台”来停止相册。

备份前先停止相册，然后复制整个项目 data/ 文件夹；若使用了 --data，备份实际指定的数据目录。它包含索引、缩略图、收藏与标注，原照片需要另行备份。网页导出的 JSON 可留档，但当前没有 JSON 导入还原功能。

更新源码前先停止相册并备份数据目录。将新版本解压到新文件夹，把原 data/ 复制过去，再双击 打开相册.cmd。保存的目录、星标与标注会保留；若使用 --data，继续指定原数据目录。不要复制旧 .venv/，新位置会重新准备运行环境。克隆仓库的用户可按 README 使用 git pull --ff-only。

从 0.1.1 升级时，第一次需要在欢迎页确认原照片目录，也可以沿用原来的 --source 参数。旧版没有保存目录；未确认来源的旧索引会保留，确认后重新读取照片并沿用已有星标和标注。

macOS / Linux 与手动安装

安装 Python 3.10 或以上版本，完整解压源码后，在项目文件夹的终端运行：

python3 install.py
.venv/bin/python app.py --open-browser

网页首次使用和更换目录的流程相同。没有桌面文件夹选择窗口的环境，使用网页中的完整路径输入即可。

Windows 如需手动安装，可在项目文件夹的终端运行 python install.py 或 py -3 install.py。随后运行 .\打开相册.cmd。

进阶用法：从终端指定 --source 也会保存为以后使用的照片目录，下次直接双击启动文件会沿用。先停止已运行的相册，再执行：

Windows：
.\打开相册.cmd --source "D:\VRChatPhotos"

macOS / Linux：
.venv/bin/python app.py --source "/你的/VRChat照片目录" --open-browser

找不到照片或打不开？

  • 首次安装失败：查看启动窗口的提示，确认已安装 Python，并能联网下载依赖。重新双击启动文件可以重试；也可运行上面的手动安装命令。
  • 选择目录失败：确认路径存在且可以读取，或使用“手动填写文件夹路径”。选择器取消不会更改相册。
  • 空相册：核对网页中的目录、清空搜索与筛选，并确认照片已写入完成。空文件夹可以保存，之后拍下的照片会自动出现。
  • 连接中断：检查启动窗口是否还在运行，重新启动后再打开 http://127.0.0.1:18764。
  • 端口被占用：关闭之前的相册，或运行 .\打开相册.cmd --port 18765 并使用新端口。
  • 安全软件拦截：先记录具体提示与文件名，在仓库提出问题以便检查。
